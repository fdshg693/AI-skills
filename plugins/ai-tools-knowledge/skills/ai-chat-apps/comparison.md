## 同じ名前でも中身が違うもの

名前が同じでも、範囲・単位・提供条件が違う。比較の回答では「同じ機能」と言い切らず、違いを添える。

- **Projects / Notebooks**: ChatGPT の Projects と Claude の Projects（旧版）は、チャット・ファイル・指示をまとめる点で近い。Claude の新版 projects（beta）は「1 プロジェクト = 1 会話」で、並列スレッドがクラウドで動く。旧版か新版かを確かめる。Gemini の Notebooks は別アプリの Gemini Notebook と同期するので、上限・共有の仕様が Gemini アプリの記事に無いことがある
- **Canvas**: Gemini の Canvas は今の機能。ChatGPT の canvas は新しいモデルでは使えず、writing blocks・code blocks が後継。Claude の Artifacts はテンプレート（Docs・Slides・Design 等）を持つ別の仕組みで、どちらとも 1 対 1 ではない
- **Skills**: 3 アプリとも Agent Skills 系の「必要時に読み込む指示」だが、提供範囲が違う。ChatGPT は Business 以上（個人プランは GPT の移行や plugin 経由で持つ）、Gemini は 18 歳以上の個人アカウント（仕事・学校は今後）、Claude は Free を含む全プラン（コード実行が前提）
- **Plugins**: ChatGPT の Plugins は skills・apps・extensions の束で、GPTs の移行先。2023 年のベータ版「ChatGPT plugins」とは別物。Claude の Plugins は skills・connectors・sub-agents の束で、有料プラン。web の chat では一部の部品（hooks・sub-agents・ローカル MCP）が動かない
- **Memory**: ChatGPT・Claude はチャットをまたいだ記憶。Gemini は「Memory」（旧 Past chats）に加え、Gmail などの Google アプリを横断する Personal Intelligence が別にある
- **Scheduled tasks / Schedules**: Gemini はタスクのスケジュールとチャットのスケジュールが別の機能で、条件も違う
- **エージェント**: ChatGPT agent は終了済みで、ChatGPT Work が後継。Claude Cowork はデスクトップでのローカル作業も含む。Gemini の auto browse は gemini.google.com ではなく Chrome の中で動く

## カスタムアシスタントの移行（2026-11 時点）

3 アプリとも、GPTs・Gems のような「カスタムアシスタント」から skills・plugins へ移っている。旧名で聞かれたら、まず移行先を示す。

| アプリ  | 旧機能                   | 新機能                                           | 日程・条件                                                                                                                       | 根拠                                                                      |
| ------- | ------------------------ | ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| ChatGPT | custom GPTs・GPT Store   | Plugins（GPT の指示は plugin 内の skill になる） | 個人プランは新規作成・公開ができない。標準の廃止日は 2026-12-11                                                                  | [GPTs](chatgpt.md#gpts)                                                   |
| Gemini  | Gems                     | Skills                                           | 18 歳以上の個人アカウントは 2026-11-17 に読み取り専用、2026-12-17 に削除（skills へ自動で作り直す）。仕事・学校アカウントは 2027 | [Gems](gemini.md#gems)                                                    |
| Claude  | （単一の機能は無かった） | Projects＋Skills＋Plugins                        | 「Customize」メニューが「Plugins」に改名（2026-11）                                                                              | [カスタムアシスタント](claude-ai.md#カスタムアシスタント再利用できる指示) |

「今から作るならどれか」と聞かれたら、ChatGPT は Plugins、Gemini は Skills、Claude は用途で選ぶ（背景知識は Projects、手順は Skills、配布は Plugins）。

## 自作 MCP サーバーの接続

どれもリモート（公開 HTTPS）の MCP サーバーが前提。条件の詳細は各節の公式ページで確かめる。

| アプリ  | 機能                                                | 主な条件（要約）                                                                                                                                     | 注意                                                                                                            |
| ------- | --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| ChatGPT | [Custom MCP servers](chatgpt.md#custom-mcp-servers) | web のみ。プラン条件は公式どうしで食い違う（ヘルプ記事は Business・Enterprise/Edu、開発者ドキュメントは制限なし。Plus の実画面で追加画面を確認済み） | 食い違いを両方示し、実画面での確認を促す。ローカルのサーバーは Secure MCP Tunnel                                |
| Gemini  | [Custom apps (MCP)](gemini.md#custom-apps-mcp)      | 18 歳以上・米国・個人アカウント・英語のみ。追加は web から                                                                                           | 日本在住では使えない                                                                                            |
| Claude  | [Custom connectors](claude-ai.md#custom-connectors) | Free を含む全プラン。Anthropic のクラウドから接続する                                                                                                | ローカルの MCP は Desktop の [Desktop extensions](claude-ai.md#desktop-extensions)。Claude Code・API は別スキル |
