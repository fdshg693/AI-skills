# ai-chat-apps 評価シナリオ

参照スキルの検証（writing-skill-complex の Reference Skills: 取り出し・適用・抜けの確認）に使うシナリオと、RED（スキル無し）・GREEN（スキル有り）の記録。

- 正解はその時点の公式ページで判定する。正解の値はここに固定しない（すぐ古くなる）。書くのは「判定に使う公式ページ」と「失敗の型」。
- 実行方法: `general-purpose` サブエージェントに 1 シナリオずつ並行で投げる。Skill ツールとリポジトリ内ファイルの参照を禁止し、WebSearch / WebFetch は通常どおり使わせる。回答の後に「調べたか・ツール呼び出し回数・根拠 URL・記憶だけで書いた部分・自信度」を自己申告させる。
- 判定: ○ 正答で公式本文に基づく / △ 結論は概ね正しいが重要な欠落・根拠不足 / × 誤答または重要な誤誘導

### 補足

- 7/8 件が実際に Web を調べた。記憶だけで答えたものは無い。問題は「調べ方」と「何を正とするか」で、記憶の古さそのものより、公式本文に届かないまま検索抜粋や古い記事で埋める点が大きい。
- 横断比較（S6・S7）は 1 件あたり 8〜9 手かかり、それでも ChatGPT 側の本文には届かなかった。
- S1 のプラン条件（2026-11-18 に `web-lookup page` で本文を確認）: ヘルプ記事 `12584461` は「Business と Enterprise/Edu の web」とし、FAQ で「Full MCP は Business・Enterprise/Edu のみ、Pro は read/fetch 権限で接続可」とする（Plus には言及なし）。一方、開発者ドキュメント `custom-mcp-server` はプラン制限を書かず「personal plugins に出る」とし、個人アカウントでの利用を前提にしている。第三者記事は「Plus 可」「Plus 不可」に割れる。地域（日本）による制限の記述はどちらにも無い。当初はヘルプ記事だけを正として × と判定したが、ユーザーの指摘で見直した。日本の Plus アカウントの実画面（2026-11-18）で、サイドバー「プラグイン」→ 右上「追加」→「カスタム MCP サーバーを追加」が開くことを確認した（項目: アイコン・名前・説明・接続タイプ〔サーバー URL／トンネル〕・認証〔OAuth 等〕・OAuth の詳細設定・リスクの承認チェック・「プラグインとして作成」）。よって **Plus でも追加できる**。ヘルプ記事の FAQ にある「Full MCP は Business・Enterprise/Edu のみ」が Plus の書き込みツールを制限するかは未確認。
- S6 で `support.google.com/gemininotebook` という別のヘルプセンターが見つかった。Gemini アプリの notebooks との関係はステップ 4 で確認する。
