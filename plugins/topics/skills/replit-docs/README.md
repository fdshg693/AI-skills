# Replit Docs の保守

公式の `https://docs.replit.com/llms.txt` 以下の階層索引と `llms-full.txt` を取得する。2026-11-11 の観測では索引は多言語で約 2,678 ページ、全文は英語約 484 ページだった。全文の `# タイトル` と直後の `Source:` は実測した形式であり、公式の区切り保証ではない。形式や URL を検証できない場合は誤った抽出をしない。

固定 excerpt では対象外の本文を発見できないため、階層索引と全文の検索を使う。各回答では個別ページを取得して裏付ける。異なる CDN の応答は単一時点の資料とは限らず、取得時刻と上流更新時刻も異なる。

キャッシュは同ディレクトリの `output/` に保存し Git には含めない。`uv run python webref_cli.py update --force` で更新できる。初回取得にはネットワークと書き込み権限が必要。上限は観測値に余裕を持たせており、索引 64 件・深さ 8・ページ 10,000 件、索引 1 件 2 MB・合計 20 MB、全文 10 MB、個別ページ 2 MB、リダイレクト 5 回を超えると失敗する。増加時は公式の現在の形式を確かめた上で調整する。

取得先とリダイレクトは HTTPS の `docs.replit.com` のみ許可し、DNS の公開アドレスを検査して接続先を固定する。プロキシは使用しない。更新途中の失敗で従来のスナップショットを上書きしない。
