# AI-skills

fdshg693/AI の Claude Code 用スキル（tools に依存しない汎用プラグイン群）。マーケットプレイス定義はアンブレラ（fdshg693/AI）の .claude-plugin/marketplace.json にあり、各プラグインはこのリポジトリの plugins/<name> を指す。

このリポジトリは [fdshg693/AI](https://github.com/fdshg693/AI) のサブモジュール（`skills/`）です。生成・検査・ワークスペース（uv / pnpm）はアンブレラ側にあるため、アンブレラから clone して使います。

```sh
git clone --recurse-submodules https://github.com/fdshg693/AI.git
```
